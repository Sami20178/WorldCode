# WorldCode Studio

Ein eigenes, von Roblox Studio inspiriertes Open-Source-Web-Editor-Projekt.

## 📱 Android APK

**[⬇️ Android APK herunterladen – v0.0.1](https://github.com/Sami20178/WorldCode/releases/tag/v0.0.1)**

Die Android-APK wird automatisch mit GitHub Actions gebaut und als echtes GitHub Release veröffentlicht, sobald ein Versions-Tag wie `v0.0.1` erstellt wird.

## Aktuelle Funktionen

- 3D-Viewport mit Three.js
- Explorer mit Workspace/World/Parts
- Parts hinzufügen und löschen
- Objekt auswählen
- Position X/Y/Z bearbeiten
- Play/Stop-Modus
- Mobile-freundliches Layout

## Start

Öffne `index.html` in einem modernen Browser. Für GitHub Pages kann das Repository als statische Website veröffentlicht werden.

> Hinweis: Dieses Projekt ist **kein Roblox Studio** und nicht mit Roblox verbunden. Es ist ein eigenes Studio-ähnliches Projekt.
